## Flashcards

Q1. What BEST describes text that is not encrypted?

A: Plaintext

Q2. Why might the company want to enable encryption on its computers' hard drives?

A: To prevent unauthorized access to data on a stolen device

Q3. What framework should the marketing firm use to ensure the insecure connection message does not appear?

A: Public key infrastructure

Q4. Why might seemingly benign images still be a threat?

A: They contain steganography

Q5. Which key exchange method provides perfect forward secrecy?

A: Diffie-Hellman

Q6. What describes the position the certificate company once had but has now lost?

A: Certificate Authority

Q7. Which encryption strategy is MOST effective to protect against physical theft of drives?

A: Incorporate self-encrypting drives (SEDs)

Q8. What should the marketing firm purchase and set up so the page shows as secure?

A: Digital certificate

Q9. Which component is required for drive encryption to work?

A: TPM

Q10. What type of encryption best protects SQL data while in use?

A: Database-level encryption

Q11. Which encryption method best supports multiple users with different access levels?

A: A combination of volume and file encryption

Q12. How might expired certificates still appear valid?

A: The CRL still requires updating

Q13. What encryption product should secure the wireless network?

A: Wi-Fi Protected Access

Q14. What file contains the information used in a digital certificate, including the public key?

A: CSR

Q15. What should the browser use to block revoked certificates?

A: CRL

Q16. What is the BEST approach to secure data at rest, in transit, and in use?

A: Asymmetric and symmetric encryption

Q17. How should the consultant describe cryptographic hashing?

A: Hashing produces a fixed-length string of bits from an input plaintext that can be of any length

Q18. Which data state was MOST likely compromised?

A: In use

Q19. What system helps verify the identity of remote users to prevent on-path attacks?

A: Digital certificates managed by a Certificate Authority (CA)

Q20. Which cryptographic solution adds a random value to each plaintext input?

A: Salt
