# Linux VM Lab

## Objective

The purpose of this project is to build a foundation in Linux by creating an Ubuntu virtual machine and becoming comfortable working in the terminal. Throughout this lab, I documented the setup process, practiced common Linux commands, and recorded what I learned along the way.

## Why Linux?

Linux is widely used in IT and cybersecurity because it powers many servers, cloud environments, networking devices, and security tools. Having a solid understanding of Linux is an important skill for system administration, troubleshooting, scripting, and many cybersecurity roles. This project is my first step toward becoming more comfortable using Linux.
