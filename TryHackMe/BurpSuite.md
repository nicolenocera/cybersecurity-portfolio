This room walked me through the basics of using Burp Suite for intercepting and modifying HTTP traffic. I practiced capturing requests using the proxy tool and got familiar with the interface in general. It helped me see how websites communicate behind the scenes and how I could step in and change data before it reaches the server.

I also played around with tools like Repeater and Decoder. Repeater let me send the same request over and over while tweaking inputs, which is super useful for testing how a server reacts to different values. Decoder was helpful for translating encoded data like base64.

A big takeaway was just understanding how useful Burp is for manual testing, especially when you want to inspect, modify, or repeat traffic. I’ll probably be using this tool a lot going forward.
