## Burp Suite Basics

Before starting the Authentication labs, I wanted to get familiar with Burp Suite first.

The first thing I did was type in Amazon.com just to see what would happen. I wasn't expecting to see so many requests.

It was cool seeing all the GET and POST requests being sent. I still don't know exactly what everything means yet, but it helped me understand that every website is constantly sending requests back and forth in the background.
