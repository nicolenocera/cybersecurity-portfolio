## 🔍 Key Burp Suite Tabs

| Tab       | Purpose                                       |
|-----------|-----------------------------------------------|
| Proxy     | Intercepts requests between browser & server  |
| Repeater  | Manually resend & edit requests               |
| Target    | Shows site map and structure                  |
| Decoder   | Encode/decode data like base64                |

---

📘 Tip: Only intercept traffic **within your scope** in Burp to avoid overwhelming logs and capturing unnecessary data.
