This room focused on understanding how different network services work and how attackers can interact with them during enumeration and exploitation.

I worked with services like FTP, SSH, and Telnet — all of which are commonly found during scans. I learned how to connect to them using tools like `ftp`, `ssh`, and `telnet`, and how to identify weak configurations or default credentials.

The room emphasized that just finding open ports isn’t enough — you have to figure out what service is running and how to interact with it properly. I practiced using `nmap` scripts and basic command-line tools to gather info on these services.

One thing I took away is that attackers don’t always need fancy exploits. Sometimes a misconfigured FTP server with anonymous login can be all it takes. This made me realize how important service hardening and access control is.
